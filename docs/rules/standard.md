# Standard Gomoku（标准五子棋）

在自由式基础上加「**恰好五连**」限制，但双方仍无禁手。基础概念见 [`fundamentals.md`](./fundamentals.md)。

## 规则

- **胜负**：率先连成**恰好 5 枚**同色棋子者获胜。
- **长连（≥6）不算赢**：六枚及以上的连子（overline）不构成胜利。一手棋若只形成长连而无恰好五连，不算赢。
- **双方均无禁手**——这是与连珠的关键区别（连珠只约束黑方且黑方长连判负；标准则双方都「长连不算赢」但也不判负）。
- **黑方先行**；竞技中常叠加开局规则（见 [`openings.md`](./openings.md)）平衡先手。
- **平局**：棋盘填满无人成恰好五连。

## 棋盘

- 通常 **15×15**。

## 边界说明

- 「恰好五」的判定针对**最长连续同色段**：若某方向最长连续段为 6+，该方向不算赢（即便其中含有长度为 5 的子段）。
- 因双方无禁手，黑方可以走出长连——只是不算赢、也不判负，对局按常规继续。

## 与其它变体的关系

- 去掉「恰好五」（长连也算赢）→ [`freestyle.md`](./freestyle.md)。
- 加黑方禁手（含黑长连判负、白长连算赢）→ [`renju.md`](./renju.md)。
- Gomocup `rule` 码 = **1**。
