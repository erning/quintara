# Caro（Gomoku+）

Caro 是越南流行的五子棋变体（Gomocup 称 Gomoku+）。在「恰好五连」基础上，要求该五连不被对方两端封死。基础概念见 [`fundamentals.md`](./fundamentals.md)。

## 规则

- **胜负**：率先连成**恰好 5 枚**同色棋子，**且该五连不被对方棋子在两端同时封堵**者获胜。
  - 即：五连的两个紧邻延长点，若**两端都是对方棋子**，则不算赢；只要**至少一端开放**（空点 / 或——视解释——棋盘边界）即算赢。
- **长连（≥6）不算赢**（同 standard）。
- **双方均无禁手**。
- **黑方先行**；可叠加开局规则。
- **平局**：棋盘填满无人取得合规五连。

## 待澄清点：棋盘边界是否算「堵」

不同实现对「贴边的五连、另一端被对方堵」是否算赢有分歧：

- **边界不算堵**（常见解释）：贴边五连只要另一端开放即算赢。
- **边界算堵**：贴边且另一端被堵 → 两端皆「堵」→ 不算赢。

采用哪种应在具体实现中显式声明。本项目（quintara）采用「**边界不算堵**」。
