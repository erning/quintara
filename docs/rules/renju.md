# Renju（连珠）

连珠是五子棋的**职业 / 竞技标准化**版本，通过对**先手（黑方）**施加禁手来平衡先手优势。本文件的禁手定义依据 Renju International Federation（RIF）官方《International Rules of Renju》。基础概念见 [`fundamentals.md`](./fundamentals.md)，开局规则见 [`openings.md`](./openings.md)。

## 1. 胜负

- **黑方**：必须连成**恰好五连**才算赢；走出长连（≥6）属禁手、判负（§3）。
- **白方**：连成 **5 枚或更多**即胜——白方长连等价于五连，算赢；白方**无任何禁手**。
- **平局**：棋盘填满无人取胜；竞技中常加手数上限（如 Gomocup 连珠 200 手判和）。

> 不对称是连珠的本质：约束只加在先手黑方。

## 2. 棋盘与开局

- 棋盘 **15×15**。
- 黑方先行。**开局**由专门的开局规则决定（平衡先手）：传统规定黑首手落天元；竞技用 RIF / Yamaguchi / Soosõrv-8 / Taraguchi-10 等系统（见 [`openings.md`](./openings.md)）。

## 3. 黑方禁手（forbidden moves）

黑方在**不同时达成五连**的前提下走出下列任一情形，即为禁手，**黑方判负**：

1. **长连（overline）**——六子或以上连续。
2. **双四（double-four）**。
3. **双三（double-three）**。

> **五连优先**：若黑方某一手**同时**达成五连与某种禁手，则五连优先、黑方获胜——禁手仅在「未同时成五」时才致负。

### 3.1 基础术语（RIF 原文定义）

- **五连（five in a row）**：一条直线上五枚连续棋子。
- **长连（overline）**：一条直线上六枚或更多连续棋子。
- **四（four）**：一行中含四枚同色棋子，**再加一枚即可成五连**的棋形。
- **活四（straight four）**：一个不间断的四子棋形，**存在两个不同的点**各加一子均可成五连。
- **三（three）**：一个棋形，**在不同时成五连的前提下，再加一子即可成为活四**。

### 3.2 双四（double-four）

在某交叉点落子，**同时形成不止一个「四」，且这些四在该交叉点交汇**，即为双四。两个四可分属不同轴向，也可在同一直线上（「四-四」夹形），只要都经过该落子点。

### 3.3 双三（double-three）

在某交叉点落子，**同时形成不止一个「三」，且这些三在该交叉点交汇**，即为双三。

**例外（RIF 递归条款）**：某些双三对黑方是**允许**的。当其中**至多一个**「三」能在加一子后真正成为活四（且这个把它变成活四的点本身不构成长连、双四或被禁的双三）时，该双三不算禁手。

> 这条例外是**递归**的：判定一个「三」是否「真三」，要看能否落子使其成活四；而那个落子点若本身是黑方禁手点，则该路不成立。正确实现需带「正在判定点」栈的递归求解，并对深度设上限兜底。这是连珠规则中最易出错的部分。

### 3.4 长连（overline）

黑方走出六子或以上连子、若未同时成五，即判负。（白方长连等价五连，算赢。）

## 4. 与 Gomocup

- Gomocup `rule` 码 = **4**。Gomocup 连珠在 RIF 基础上：开局由连珠专家准备、不限 26 型；不允许 pass；任意一局 **200 手后自动判和**。
