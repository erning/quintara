# 开局规则（先手平衡）

先手（黑方）在五子棋中天然占优。**开局规则**用于削弱先手优势，是与胜负规则、棋盘大小**正交**的一维——可叠加到任意变体上。基础概念见 [`fundamentals.md`](./fundamentals.md)。

开局规则分两大思路：**限制型**（限制先手早期落点）与**交换型**（让后手有机会换色）。连珠另有一套基于「指定多个候选第五手 + 换色」的专用系统。

## 1. 限制型

### Pro（职业开局）
- 黑方第一手必须落在**天元**（中心）。
- 白方第一手可落任意点。
- 黑方第二手（全局第 3 手）必须落在**距中心至少 3 个交叉点之外**（即中心 5×5 区域之外）。

### Long Pro（长职业开局）
- 同 Pro，但黑方第二手须落在**距中心至少 4 个交叉点之外**（更大的禁区）。

> Pro / Long Pro 用于早期世锦赛（1989、1991）。先手胜率仍偏高（约 67%），后被交换型取代。具体禁区距离不同来源略有出入，以上为常见表述。

## 2. 交换型（Gomoku）

### Swap
1. 先手方在盘上摆**三枚**棋子（两黑一白，位置任意）。
2. 后手方二选一：**执白续行**，或**交换执黑**。

### Swap2（当前 Gomoku 世锦赛标准，2009 起）
1. 先手方摆**三枚**（两黑一白）。
2. 后手方**三选一**：
   - **执白续行**；
   - **交换执黑**；
   - **再摆两子**（一白一黑），然后把**选色权交回先手方**。
3. 若进入第 3 选项（盘上 5 子），由选色方决定换色或继续。

Swap2 把先手胜率从 Pro 的约 67% 拉到约 52%，且因第三选项的不确定性限制了单方深研某条线路。协议实现见 [`../protocol/gomocup.md`](../protocol/gomocup.md) 的 `SWAP2BOARD`。

## 3. 连珠专用开局系统（RIF 演进）

连珠竞技开局围绕「**指定若干候选第五手 + 可换色**」展开，逐代放开可达的开局型（共 26 种合法开局）。历代官方规则：

| 规则 | 启用年份 | 要点 |
| --- | --- | --- |
| **RIF** | 1995 | 先手摆 3 子（2 黑 1 白）→ 后手选执黑/白 → 白补第 4 子 → 第 5 手由白方**指定两个候选**、黑方落较弱者；之后正常进行。 |
| **Yamaguchi** | 2009 | 在 RIF 基础上扩展，提出第 5 手候选数可由提议方指定，开放更多开局。 |
| **Soosõrv-8** | 2017 | 候选第五手由**摆第 4 子的玩家**声明，数量 **1–8** 个，对方可选择换色；开放**全部 26 种**开局。竞技用（性质最接近传统连珠开局）。 |
| **Taraguchi-10** | 2024 | 更简单，用于**通讯赛**。 |

> 现状（截至 2024+）：通讯赛用 Taraguchi-10（简单），现场赛用 Soosõrv-8。

## 4. 自动开局（管理器侧）

Piskvork / Gomocup 管理器支持**自动开局**：对局开始时由管理器自动摆好 **3 或 5** 手开局子，再交给双方对弈。

- 用途：锦标赛中保证同一对 AI 的多局不重复（配合 repeat/games）。
- **随机旋转 / 镜像**：开局坐标可随机平移 + 旋转 / 翻转（8 种变换），增加多样性；正式赛不建议开启。
- 开局库文件（如 `openings.txt`）以「相对中心的偏移」或坐标序列记录。
